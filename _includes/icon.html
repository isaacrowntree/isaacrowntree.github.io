{%- comment -%} Inline stroke icons — replaces the Font Awesome CDN (~110KB CSS + ~250KB of webfont from a third origin) with ~1KB of markup per use. Sized 1em so they inherit font-size exactly like the glyphs they replace. Decorative by default (aria-hidden). Pass label="…" when the icon is the only content of a link or button and needs an accessible name. Usage: {% include icon.html name="github" %} {%- endcomment -%} {%- assign n = include.name -%} {%- if n == "github" or n == "x" or n == "linkedin" or n == "instagram" or n == "quote-left" -%} {%- else -%} {%- endif -%}
